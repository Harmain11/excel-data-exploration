# Excel Data Exploration

## Overview
This notebook demonstrates basic data exploration using an Excel file. It loads the data, inspects the columns, displays the first rows, and shows value counts for the 'Region' column.

## Features
- Load data from an Excel file using pandas
- Inspect column names
- Preview first rows of the dataset
- Calculate and display value counts for a specific column

## Tech Stack
- Python
- Jupyter Notebook / Google Colab
- pandas

## How to Use
1. Place your Excel file (`Sajjad_data.xlsx`) in the working directory.
2. Run the notebook cells sequentially.
3. Modify the notebook to explore other aspects of your data if needed.
